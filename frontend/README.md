# SPR Frontend (React + Vite) — Ardhi University

## Run
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build in dist/

## Where things are
- src/components/BannerSlider.jsx  -> auto-sliding banner (arrows, dots, swipe, progress bar)
- src/components/Ticker.jsx        -> continuously moving text banner (marquee)
- src/styles.css                   -> all colors are CSS variables at the top (ARU logo palette)
- src/data.js                      -> slides, menu, sample projects (replace with your Django API)
- public/assets/                   -> logo and banner images
